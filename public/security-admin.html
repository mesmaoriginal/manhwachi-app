مسدود کردن

توجه: در ایران بسیاری از کاربران موبایل یک IP مشترک دارند؛ بلاک دائمی IP یا بازه‌ی بزرگ ممکن است کاربر عادی را هم ببندد. برای هاست‌ها و سرورهای اسکرپ (دیتاسنتر) مناسب است.

ردیابی دزد (از روی کد واترمارک)

کد ۸حرفیِ روی عکس، یا gid / IP / user id را بده؛ همه‌ی هویت‌های مرتبط (کوکی‌ها، حساب‌ها، IPهای عمومی، مرورگرها) را نشان می‌دهد و می‌توانی همه را یک‌جا مسدود کنی.
